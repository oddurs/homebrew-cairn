# homebrew-cairn

A Homebrew tap for [cairn](https://github.com/oddurs/cairn) — a roadmap and
issue manager that lives in your repository.

```sh
brew tap oddurs/cairn
brew install cairn
```

Installs the binary, its manual page, and completions for bash, zsh and fish.

The formula is generated from a release of the main repository; report problems
[there](https://github.com/oddurs/cairn/issues).
